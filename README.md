# base-tools

The onchain toolstack for **Base** builders and degens.

A directory of Base ecosystem tools — trading bots, terminals, wallet trackers, bridges, DEXs — plus a live trending-tokens board pulling real-time data from GeckoTerminal's onchain API.

## Live site

https://araxis33.github.io/base-tools/

## What's inside

- **Trading Bots** — Banana Gun, GMGN.ai, Maestro
- **Terminals** — DexScreener, DEXTools, GeckoTerminal
- **Tracking & Alerts** — Cielo Finance, RayBot
- **Bridges** — Base Bridge, Superbridge, Brid.gg
- **DEX & Swap** — Aerodrome Finance, Uniswap, Matcha

Plus a live "Trending on Base" board: token, contract address (linked to Basescan), price, 24h change, volume — refreshed client-side, cached locally, with an honest "unavailable" state if the API is rate-limited.

## Stack

Single static `index.html`, no build step, no backend. Client-side fetch only.

## Notes

Links are direct — no affiliate/cashback programs. Not financial advice; always verify contract addresses before trading.
